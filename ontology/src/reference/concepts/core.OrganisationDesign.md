# organisation design (core.OrganisationDesign)

## Definition
Configuring an organisation from Binner's models, methods, procedures and tools; the sense of 'Konfigurationsmanagement' in his 2018 book.

## Common confusions
- Not configuration (control of controlled items): B2 pp. 211–212 uses Konfigurationsmanagement for document control, which maps to configuration.

## Source and mapping
- MITO model definition, naming guardrail (B1 preface; p. 11); A: two senses (B1 pp. 93, 542–543; B2 pp. 211–212).
- B1 = Binner, *Organisation 4.0 – MITO-Konfigurationsmanagement* (2018); B2 = Binner, *Ganzheitliche Businessmodell-Transformation* (2020); printed pages.
- MITO model definition: governance-kernel `docs/core/definitions/mito-model.md`.
