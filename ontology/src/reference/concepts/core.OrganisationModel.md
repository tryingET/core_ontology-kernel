# organisation model (core.OrganisationModel)

## Definition
The model of how an organisation is structured and run. In AI Society this is Binner's MITO model, which he calls a "Metamodell der Organisationsentwicklung und -gestaltung" (B1 p. 57). A company configures it into three organisation subsystems, which together make up its "ganzheitliche Organisationsordnungsstruktur" (B1 pp. 15, 325):
- the goal system (Organisationszielsystem);
- the process model (Organisationsprozessmodell);
- the leadership system (Organisationsführungssystem).

## Typical usage
- The MITO model combines several model views into one: structure, procedure, description, analysis, construction, explanation, system (cybernetics) and design models (B1 p. 57).

## Common confusions
- 'Model' is never bare: an organisation model, a system model or an LLM.
- Binner's "MITO-Systemmodell (Kybernetik)" is one view inside the MITO model, the control loop; it is not a system model in the engineering sense.
- Binner writes "MITO-Modell", not "Organisationsmodell"; in B1 that word occurs only in the title of another author's book (Büche and Chrobok 1994, bibliography).
