# Policy (core.Policy)

## Definition
Eine formalisierte Regel, die Verhalten einschränkt oder überprüft.

## Typical usage
- Used for enforceable rules with explicit scope and checks.

## Common confusions
- Confused with informal guidelines that cannot be validated.
