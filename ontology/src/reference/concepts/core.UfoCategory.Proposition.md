# UFO proposition (core.UfoCategory.Proposition)

## Definition
The UFO category of propositional contents: abstract representations of the situations that beliefs, desires and intentions refer to; the content of an intention is a goal.

## Typical usage
- Test question: Can a situation satisfy it?
- Governance-core concepts in this category: core.Claim, core.Goal.
