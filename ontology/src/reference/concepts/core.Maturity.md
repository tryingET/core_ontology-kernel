# maturity (core.Maturity)

## Definition
How far round the MITO loop a process is institutionalised (defined, planned, executed, measured, improved); a level counts as reached only when every segment reaches it.

## Common confusions
- NASA's document states are artefact status; TRL is technology readiness.
