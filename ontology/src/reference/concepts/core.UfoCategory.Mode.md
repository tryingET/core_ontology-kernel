# UFO mode (core.UfoCategory.Mode)

## Definition
The UFO category of moments that inhere in one bearer and cannot be measured on a value scale, including dispositions and modes that also depend on others.

## Typical usage
- Test question: Whose is it, and can it be measured on a scale?
- Governance-core concepts in this category: core.ActorCapability, core.Authority, core.Objection, core.Permission, core.StakeholderExpectation.
