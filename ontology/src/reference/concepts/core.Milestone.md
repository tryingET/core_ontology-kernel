# Milestone (core.Milestone)

## Definition
A timeboxed outcome checkpoint with explicit exit criteria; groups multiple work items.

## Typical usage
- A milestone groups work items and provides a shared target for progress tracking.

## Common confusions
- Confused with a release (which may be a milestone outcome, but not all milestones ship a release).
