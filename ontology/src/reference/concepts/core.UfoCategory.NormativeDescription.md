# UFO normative description (core.UfoCategory.NormativeDescription)

## Definition
The UFO-C category of social objects that define rules recognised by at least one social agent, such as regulations, directives and plan descriptions.

## Typical usage
- Test question: Which rules does it define, and who recognises them?
- Governance-core concepts in this category: core.Directive, core.Guidance, core.Policy, core.Requirement.
